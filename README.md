# Десертрум — витрина

Демо-сайт кондитерских в Йошкар-Оле.

- Три точки: Чавайна, 8 · Советская, 128 · Чернякова, 3
- Заказы уходят менеджеру: [@dessertroommanager](https://t.me/dessertroommanager)
- Каталог: `data/catalog.json`, настройки бренда: `config.js`

Сайт статический: без бэкенда и базы данных. Покупатель собирает заказ,
сайт формирует готовый текст и открывает чат с менеджером в Telegram.
